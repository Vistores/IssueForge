# Terms of Use

Last updated: May 14, 2026

These terms describe the intended use of the IssueForge project template and demo application.

## Project Purpose

IssueForge is a full-stack issue and work tracking template for teams. It includes an Angular frontend, ASP.NET Core Web API backend, SQLite persistence, authentication, teams, projects, issues, comments, assignments and activity logs.

The repository is intended for learning, evaluation, customization and use as a starting point for team workflow products.

## Demo Use

If a public demo is provided, it should be used only for testing the interface and workflow. Do not submit sensitive personal data, production credentials, private customer data or confidential business information into a public demo.

Demo data can be reset, removed or changed at any time.

## Self-Hosted Use

When you deploy IssueForge yourself, you are responsible for:

- Server and database configuration
- User access control
- Backups and data retention
- Security updates
- Legal compliance for your users and region
- Replacing demo credentials and seed data

## Commercial Template Use

IssueForge can be adapted into a commercial template or starter product. Before selling or distributing a paid version, add a clear license that explains:

- What buyers are allowed to build with it

Do not sell third-party assets, logos or services unless you have the right to redistribute them.

## No Warranty

The project is provided as-is. It may require additional security hardening, testing and infrastructure work before public production use.

## Recommended Production Checklist

Before exposing a customized deployment publicly:

- Use HTTPS
- Configure secure authentication cookies
- Use production secrets and environment variables
- Review authorization rules
- Add database backups
- Add attachment storage limits and malware scanning if needed
- Add monitoring and logging
- Run backend and frontend build checks
- Review this Terms document and the Privacy Policy for your deployment
